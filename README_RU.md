# TruthLens

Android-приложение для вероятностной оценки того, создано ли изображение ИИ.

## Состав
- Android: Kotlin + Jetpack Compose.
- Backend: FastAPI.
- Математические признаки: средние значения и стандартные отклонения RGB, размер изображения.
- Классификация: внешний Hugging Face Inference Provider, если настроены серверные переменные.

## Важно
Математические признаки сами по себе **не доказывают**, что изображение создано ИИ. Для вердикта необходима обученная модель. Не выдавайте статистику пикселей за нейросетевое распознавание.

## Backend
Разверните папку `backend` как Docker-сервис. Настройте переменные окружения:
- `HF_TOKEN` — секретный токен Hugging Face (добавлять только в секреты хостинга, не в GitHub-файлы и не в APK).
- `HF_MODEL_ID` — ID модели классификации изображений, совместимой с Hugging Face Inference API.

Проверка: `GET /health`. Анализ: `POST /analyze` с multipart-полем `file`.

Важно: доступность модели через Inference Providers и возможная стоимость зависят от провайдера, аккаунта и выбранной модели. Не включайте платный тариф без согласия владельца.

## Android
В `app/build.gradle.kts` замените `API_BASE_URL` на HTTPS-адрес развернутого backend. Затем запустите GitHub Actions workflow **Build TruthLens APK**. APK появится в Actions → запуск workflow → Artifacts.

## Статус
Это исходный каркас приложения и API. Перед использованием необходимо выбрать и проверить совместимую модель и развернуть backend. Пока это не сделано, приложение не выдаёт фиктивный результат.
